# b1t-AI 智能助手

> 面向开发者和企业用户的私有化AI Agent框架，提供超越标准LLM的自主任务执行能力。

## ✨ 核心功能

- 🧠 **ReAct推理引擎**: 思考→行动→观察→再思考的循环推理
- 💾 **三层记忆系统**: 短期记忆 + 长期记忆 + 工作记忆
- 🔧 **内置工具集**: 网络搜索、数学计算、代码执行、文件管理
- 📎 **文件上传识别**: 支持TXT/MD/PDF/DOCX/图片
- 📱 **移动端适配**: 完美支持手机浏览器访问
- 🔒 **私有化部署**: 数据完全本地可控

## 🔑 使用说明

1. 打开页面后，在设置中填入你的 **DeepSeek API Key**
2. 开始对话，享受AI智能助手服务

## 🛠 技术栈

- **后端**: FastAPI + Uvicorn + DeepSeek API
- **前端**: 原生HTML/CSS/JS + Marked.js
- **部署**: Docker + Hugging Face Spaces
