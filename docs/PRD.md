## 1. 产品概述

### 1.1 产品定位

b1t-AI 是一款面向个人开发者和企业用户的智能 AI Agent 平台，基于 DeepSeek 大语言模型构建，提供对话交互、文件处理、代码执行、网络搜索等一站式 AI 能力。

### 1.2 目标用户

| 用户类型 | 需求场景 | 核心功能 |
|---------|---------|---------|
| 个人开发者 | 代码辅助、技术问答、文件处理 | 代码执行、文件管理、ReAct推理 |
| 产品经理 | 需求分析、文档撰写、竞品调研 | 网络搜索、文件生成、多轮对话 |
| 企业用户 | 内部知识库、自动化办公 | 文件管理、会话历史、工具扩展 |
| AI爱好者 | 体验最新AI能力 | 图片识别、流式对话、工具调用 |

### 1.3 核心价值主张

1. **开箱即用**: 无需复杂配置，一键启动本地服务
2. **双模对话**: 快速问答 + 深度推理，满足不同场景
3. **文件智能**: 支持多种格式上传，AI自动解析理解
4. **安全可靠**: 沙箱执行环境，多层安全防护
5. **中文优化**: 全中文交互，更符合国内用户习惯

## 2. 功能需求

### 2.1 对话系统

#### 2.1.1 快速对话模式

**需求描述**: 直接调用 LLM API，无需工具调用，适用于日常问答

**功能点**:
- [x] 支持多轮对话上下文
- [x] 流式响应显示
- [x] Markdown 渲染支持
- [x] 代码块语法高亮
- [x] 对话历史本地存储

**验收标准**:
- 首 token 响应时间 < 3 秒
- 支持 10 轮以上上下文记忆
- 代码块自动识别语言并高亮

#### 2.1.2 ReAct 推理模式

**需求描述**: 基于 ReAct 论文实现的多步推理框架

**功能点**:
- [x] Thought-Action-Observation 循环
- [x] 自动工具选择和调用
- [x] 迭代次数限制 (默认8次)
- [x] 超时保护机制 (120秒)
- [x] 失败自动降级

**验收标准**:
- 复杂任务分解为多个步骤执行
- 工具调用成功率 > 90%
- 超时后返回当前进度

### 2.2 文件处理系统

#### 2.2.1 文件上传

**支持格式**:

| 类型 | 格式 | 大小限制 | 优先级 |
|------|------|---------|--------|
| 文本 | .txt, .md, .csv, .json | 10MB | P0 |
| 代码 | .py, .js, .html, .css, .java, .cpp, .go, .rs | 10MB | P0 |
| 文档 | .pdf | 10MB | P1 |
| 办公 | .docx | 10MB | P1 |
| 图片 | .png, .jpg, .jpeg, .gif, .webp | 5MB | P0 |

**功能点**:
- [x] 拖拽上传
- [x] 点击选择上传
- [x] 多文件同时上传
- [x] 上传进度显示
- [x] 文件预览和删除

#### 2.2.2 文件内容提取

**需求描述**: 自动提取文件内容并发送给 AI 分析

**实现方案**:
- 文本文件: 直接读取内容
- PDF: PyPDF2 库提取文本
- DOCX: python-docx 库提取段落
- 图片: SiliconFlow Vision API 识别

### 2.3 工具生态系统

#### 2.3.1 计算器

**功能描述**: 安全的数学表达式计算

**需求**:
- [x] 支持 +, -, *, /, //, %, ** 运算
- [x] 支持括号优先级
- [x] 支持函数: abs, round, min, max, sum, pow
- [x] AST 解析替代 eval
- [x] 禁止危险代码执行

#### 2.3.2 代码执行器

**功能描述**: 在沙箱环境中执行代码

**需求**:
- [x] 支持 Python 语言
- [x] 支持 JavaScript 语言 (Node.js)
- [x] 子进程隔离执行
- [x] 30秒超时控制
- [x] 危险代码检测
- [x] 输出限制 1MB

**安全规则**:
```
禁止: import os, import subprocess, eval(), exec(), __import__
限制: 单核 CPU, 256MB 内存
超时: 30秒强制终止
```

#### 2.3.3 文件管理器

**功能描述**: AI 操作本地文件系统

**需求**:
- [x] 工作目录限制 (./workspace/)
- [x] 支持操作: read, write, append, list, delete
- [x] 扩展名白名单校验
- [x] 路径遍历防护

**文件类型白名单**:
```
.txt, .md, .py, .json, .csv, .html, .css, .js
```

#### 2.3.4 网络搜索

**功能描述**: 实时搜索网络信息

**需求**:
- [x] DuckDuckGo 搜索引擎
- [x] 返回结果数可配置 (默认5条)
- [x] 结果包含: 标题、URL、摘要
- [x] 无需 API Key

### 2.4 记忆系统

#### 2.4.1 短期记忆

**需求**:
- [x] 窗口大小: 10轮对话
- [x] Token 限制: 8000
- [x] FIFO 淘汰策略
- [x] 中文 Token 估算 (4字符/token)

#### 2.4.2 长期记忆 (可选)

**需求**:
- [x] ChromaDB 向量存储
- [x] all-MiniLM-L6-v2 嵌入模型
- [x] 余弦相似度检索
- [x] 相似度阈值 0.7

**记忆类型**:
- preference: 用户偏好
- fact: 重要事实
- context: 任务上下文
- learning: 学习记录

#### 2.4.3 工作记忆

**需求**:
- [x] 单次任务期间临时状态
- [x] 任务进度追踪
- [x] 中间结果存储

## 3. 非功能需求

### 3.1 性能需求

| 指标 | 目标值 | 说明 |
|------|--------|------|
| API 响应时间 | < 3s | 首 token 返回时间 |
| 文件上传 | < 5s | 10MB 文件上传处理 |
| 并发用户 | 10+ | 单实例支持 |
| 内存占用 | < 500MB | 运行时峰值 |

### 3.2 安全需求

| 类别 | 措施 |
|------|------|
| 代码执行 | AST 白名单、子进程隔离、超时控制 |
| 文件操作 | 路径规范化、扩展名白名单、目录限制 |
| API 安全 | 环境变量隔离、请求超时、重试机制 |
| 数据安全 | 敏感信息不入库、本地存储优先 |

### 3.3 兼容性需求

- **浏览器**: Chrome 90+, Firefox 88+, Edge 90+, Safari 14+
- **操作系统**: Windows 10+, macOS 11+, Linux (Ubuntu 20.04+)
- **Python**: 3.9+

### 3.4 可用性需求

- 一键启动，无需复杂配置
- 中文界面，符合国内用户习惯
- 错误提示友好，提供解决建议
- 文档完整，包含示例代码

## 4. 用户故事

### 4.1 开发者小王

> 作为一名 Python 开发者，我希望 AI 能帮我执行代码片段，以便快速验证想法。

**场景**:
1. 小王输入: "帮我计算斐波那契数列前10项"
2. AI 生成 Python 代码
3. AI 调用代码执行器运行
4. 返回执行结果

**验收标准**:
- 代码在沙箱中安全执行
- 返回结果正确
- 执行时间 < 5秒

### 4.2 产品经理小李

> 作为产品经理，我希望上传竞品分析报告，让 AI 帮我总结要点。

**场景**:
1. 小李上传 PDF 报告
2. AI 提取文本内容
3. AI 分析并总结关键信息
4. 生成结构化摘要

**验收标准**:
- 支持 PDF 格式
- 提取内容完整
- 摘要准确反映原文

### 4.3 设计师小张

> 作为设计师，我希望 AI 能识别我上传的设计稿，给出优化建议。

**场景**:
1. 小张上传 UI 设计图
2. AI 调用视觉识别
3. AI 分析布局、配色、字体
4. 给出具体优化建议

**验收标准**:
- 支持 PNG/JPG 格式
- 识别准确
- 建议具体可操作

│                      │                       │

│  └────────────────┘  │  └─────────────────┘  │
│                      │                       │
│  ┌────────────────┐  │  ┌─────────────────┐  │
│  │ 余额卡片       │  │  │                 │  │
│  └────────────────┘  │  │  对话区域       │  │
│                      │  │                 │  │
│  ┌────────────────┐  │  │  - 欢迎界面     │  │
│  │ 统计信息       │  │  │  - 消息列表     │  │
│  └────────────────┘  │  │  - 思考过程     │  │
│                      │  │                 │  │
│  ┌────────────────┐  │  └─────────────────┘  │
│  │ 历史对话列表   │  │                       │
│  └────────────────┘  │  ┌─────────────────┐  │
│                      │  │ 输入区域        │  │
│  ┌────────────────┐  │  │ - 附件按钮      │  │
│  │ 用户信息       │  │  │ - 文件预览      │  │
│  └────────────────┘  │  │ - 文本框        │  │
│                      │  │ - ReAct开关     │  │
│                      │  │ - 发送按钮      │  │
│                      │  └─────────────────┘  │

### 5.2 交互说明

**文件上传**:
1. 点击 + 按钮或拖拽文件到上传区域
2. 显示文件列表和删除按钮
3. 发送时自动上传并提取内容

**ReAct 模式切换**:
1. 默认开启 (按钮高亮)
2. 点击切换状态
3. 状态变化即时生效

**流式响应**:
1. 发送后显示思考动画
2. 内容逐字显示
3. 支持 Markdown 实时渲染
